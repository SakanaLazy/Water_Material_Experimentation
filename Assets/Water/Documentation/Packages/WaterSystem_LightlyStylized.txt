Unity's Package Manager assets are prerequisites, not copied Library/PackageCache files.
After import choose Water > Set Up Active URP Renderer. This enables opaque/depth textures, assigns layer 30 / Water Volume if available, and installs the back-face depth renderer feature.
If layer 30 is occupied, the helper stops; configure a dedicated volume layer and renderer feature manually. Put closed water renderers on that layer. Use the plane master for surface meshes and the volume master for separate closed meshes.
Choose your URP asset in Graphics/Quality settings before running setup. No project pipeline or layer settings are overwritten during import.

No demo scenes or project renderer settings are included.
Includes the plane and volume presets for this style. The shared graphs expose all style controls, but the other three styles' material presets are not included.
Packages retain shared GUIDs and can be imported together. Importing another package updates the shared assets instead of duplicating them.
The current system supports viewing water from outside. Underwater camera rendering is not implemented.
